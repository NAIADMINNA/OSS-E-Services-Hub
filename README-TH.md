# DOE Dashboard — เปิดอินโฟกราฟิกเร็วขึ้น

- การเปิดเมนูดูอินโฟกราฟิกซ้ำใช้ภาพที่โหลดสำเร็จไว้แล้ว ไม่ล้างแคชและไม่ส่งคำขอโหลดรูปใหม่โดยไม่จำเป็น
- ปุ่ม "โหลดภาพล่าสุด" ยังสั่งตรวจสอบรูปจาก Google Drive ใหม่ได้
- การตรวจสอบอัตโนมัติทุก 5 นาทียังทำงานเหมือนเดิม
- คู่มือของการ์ดทั้ง 3 และส่วนท้ายคงอยู่
